A precise instrument for color

Every feature is built to be exact where it matters and playful where it counts.

  • Spectral palettes

    Generate perceptually even palettes from a single seed color, tuned in a uniform color space so no hue overpowers the rest.

  • Caustic gradients

    Blend light the way glass does — smooth, refractive gradients that avoid muddy midpoints and banding.

  • Contrast lab

    Check every pairing against WCAG thresholds as you design, so accessible color is the default, not an afterthought.

  • Token export

    Ship your spectrum as design tokens, CSS variables, or a Figma-ready file — one source of truth, many surfaces.
