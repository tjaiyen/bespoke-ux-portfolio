01 Receiving — the first link, if it was captured

Recall readiness, checked nightly

A traceability failure is not found during an audit. It is found during a recall, which is far too late.

  • All five events, or none

    Growing, receiving, transforming, creating and shipping each have to be present with their key data elements; four out of five is a broken chain, not an 80% score.

  • Key data completeness

    An event with a missing lot code or date is an event that cannot be followed, so completeness is checked field by field rather than by counting rows.

  • Both directions

    A recall runs backwards to the source and forwards to every customer who received it, and a chain that only resolves one way fails the half that matters.

  • Nightly, not annually

    Gaps are surfaced the day they appear, when the paperwork can still be reconstructed from people's memory rather than from nothing.
